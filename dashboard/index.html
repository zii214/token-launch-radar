Reading the board. “Records no token” is the snapshot’s statement, not a claim about the world: DefiLlama’s record can lag a launch, and a versioned deployment of a protocol whose token already trades is kept off the board by the same rule that built the watchlist. An implied value is this model’s claim about what a token would be worth if the protocol’s record stayed as it is — not a prediction that a token will be issued. Farm plans are starting points for your own research, not financial advice.
